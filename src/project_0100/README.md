# Simple CLI Calculator

This project provides a minimal command-line calculator implemented in Python.

## Files

- **main.py**: Entry point that parses command‑line arguments and dispatches to the appropriate operation.
- **operations.py**: Contains the core arithmetic functions.
- **README.md**: This documentation.

## Usage

```bash
python main.py add 3 5   # Result: 8.0
python main.py sub 10 4  # Result: 6.0
python main.py mul 2 7   # Result: 14.0
python main.py div 9 3   # Result: 3.0
```

The script will print the result of the chosen operation.

## Requirements

- Python 3.6+

No external dependencies are required.
